1NCE and Pessl Instruments have rolled out the METOS by Pessl Instruments weather network globally, using 1NCE as the underlying connectivity provider [IoT Now](https://iot-now.com/2026/07/30/157665-1nce-and-pessl-instruments-connect-smart-farms-worldwide/). The deployment connects thousands of agricultural weather stations and field sensors across more than 80 countries through a single management platform.

The METOS system collects real-time data on precipitation, soil moisture, and crop disease risk. It transmits this data over LTE-M, NB-IoT, and 4G networks provided by 1NCE, which operates in more than 170 countries. Farmers access extreme weather forecasting and field analytics through Pessl Instruments' software interface. These cellular technologies reach remote rural locations where traditional connectivity is scarce, using power-saving features to keep sensors running efficiently in low-power locations for extended periods without manual intervention.

For network operators and systems integrators, the partnership demonstrates how global connectivity platforms can solve the coverage problem for massive IoT deployments in challenging agricultural environments. Pessl Instruments actively monitors every endpoint through the 1NCE platform, achieving 99.97% service availability according to the companies. Energy-saving features extend device life in remote areas, reducing truck rolls for battery replacements and maintenance. The plug-and-play model removes local connectivity complexity, allowing sensors to join the network automatically when deployed in new regions. This eliminates the need for farmers to negotiate local carrier contracts or manage regional connectivity configurations.

The deployment shows that agricultural IoT at scale requires predictable availability guarantees and consistent cross-border connectivity rather than single-radio solutions. With thousands of endpoints already live, the network provides a concrete reference for how cellular IoT can support continuous environmental monitoring across diverse geographies. The 99.97% uptime claim sets an operational benchmark for outdoor IoT in demanding conditions. For practitioners, the integration highlights that device-to-cloud connectivity for remote agriculture is now a mature commodity, shifting focus back to sensor accuracy and data analytics rather than radio logistics.
