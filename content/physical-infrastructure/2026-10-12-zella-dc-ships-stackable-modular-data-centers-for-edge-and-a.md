Zella DC introduced a stackable modular data center platform called Zella Stack at Yotta 2026 in Las Vegas, according to [Network World](https://www.networkworld.com/article/4230865/micro-data-center-company-rolls-out-stackable-data-center-for-edge-and-ai.html).

The platform uses 12 rack unit (RU) containers that measure 51.2 × 27.6 × 22.8 inches. Customers can stack up to four modules for 48RU of hardware capacity. A wheeled base module contains the infrastructure needed to operate the system, while additional IT modules stack above it. The modular design supports either air or liquid cooling, with capacity reaching 124kW. This makes the platform suitable for higher-density workloads than traditional small edge installations.

The largest configuration, Zella Stack 48, includes a base module and three IT blocks. It weighs approximately 185 kilograms (408 pounds) and stands 2.48 meters tall, with an operating noise level of about 50 decibels. Individual components can be deployed rapidly, potentially making an edge data center operational within days.

Zella Stack runs Zella Sense, a monitoring, control, and automation layer built into every cabinet. It tracks power, cooling, servers, and suspicious activity while monitoring temperature, humidity, smoke, motion, water, and doors through sensors. The system supports Simple Network Management Protocol (SNMP), Modbus, and a full application programming interface (API), with email alerting and local, Lightweight Directory Access Protocol (LDAP), Remote Authentication Dial-In User Service (RADIUS), or Terminal Access Controller Access-Control System Plus (TACACS+) authentication. This allows remote monitoring of edge locations. The platform includes access control and fire protection.

Zella Stack is currently an indoor-only offering. The company plans an outdoor version for the second half of 2027.

For network operators managing edge infrastructure, Zella Stack changes the capital deployment model. Instead of building out fixed capacity, teams can match compute expansion directly to demand growth, adding modules as AI inferencing or other edge workloads increase. The 124kW cooling capacity supports GPU-based gear that would overwhelm typical edge cabinets. Remote monitoring via SNMP and API integration lets staff manage distributed sites without routine travel, while standard authentication protocols tie into existing access control systems. The platform’s 50-decibel noise level and 2.48-meter height impose physical constraints that facility planners must account for. The planned outdoor version may address deployment flexibility, but until then, indoor space and ventilation remain limiting factors.
